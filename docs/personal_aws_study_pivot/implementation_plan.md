# Cloud Dojo - 個人用学習アプリへのピボット計画

本計画は、元々チーム向けだった「Cloud Dojo」を、**「個人（ご自身）のAWS資格取得」に特化したストイックな学習アプリケーション**として再定義するためのものです。

## User Review Required

> [!IMPORTANT]  
> 今後の開発方針について、以下の点をご確認・ご判断ください。
> 
> **1. バックエンド（データ同期）の必要性**
> スマホとPCなど、複数デバイス間で学習データ（進捗や正答率）を同期したいですか？
> - **Yesの場合**: Firebase (Firestore) や Supabase などを利用したシンプルな個人用データ同期の仕組みを導入します。
> - **Noの場合**: バックエンドは不要とし、デバイスのローカル（`localStorage` や `IndexedDB`）のみで完結する高速な完全オフラインPWAとして開発を進めます。
> 
> **2. 優先したい学習機能**
> 個人の資格取得を確実にするため、以下のどの機能を優先して実装したいですか？（複数選択可）
> - **A. 弱点克服モード**: 間違えた問題だけをストックし、集中的に再出題する機能（カテゴリ別の正答率分析含む）
> - **B. 忘却曲線ベースの復習 (Spaced Repetition)**: 一度正解した問題でも、記憶が薄れるタイミングで自動的に再出題する機能（Ankiのような仕組み）
> - **C. AI チューター機能**: 間違えた問題に対して、「なぜ間違えたのか」「AWS公式ドキュメントのどこを読むべきか」をAI（Gemini API等）が深く解説してくれる機能
> - **D. 問題データの圧倒的拡充**: とにかく大量の模擬問題をJSON形式で準備し、本番さながらのランダムテスト（65問/130分など）を行える機能
