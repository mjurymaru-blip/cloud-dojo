# Cloud Dojo - 個人学習用ピボット完了報告 (Walkthrough)

## 実装した内容

本チャットにて、チーム向けプラットフォームから個人のAWS資格学習に特化したアプリケーションへのピボットを行いました。

### 1. データ構造の拡張 (JSON & Storage)
- `clf-c02.json` と `saa-c03.json` に新しく `category` (分野) と `difficulty` (難易度) のメタデータを追加し、合計14問に拡充しました。
- `storage.js` を改修し、これまでの単なる「正答数」だけでなく、「分野別の正答率」と「間違えた問題の履歴」を `localStorage` に記録・管理できるようにしました。
- 既存のデータ構造から新しい構造への移行（マイグレーション）ロジックも組み込んでいるため、過去の学習データが壊れることはありません。

### 2. クイズ画面の改修 (`quiz.js`)
- ユーザーが各問題に答えるたびに、その問題の「分野」「正誤」「選んだ選択肢」を細かく記録する処理 (`state.recordAnswer`) を追加しました。
- クイズ終了時に、これらの詳細データを一括してストレージへ保存しています。
- URLパラメータとして `?mode=review` が渡された場合、間違えた問題（弱点）のみを抽出して出題する「復習モード」を実装しました。

### 3. コース選択UIの強化 (`index.html` & `main.js` & `components.css`)
- トップ画面のコース選択ボタンを拡張し、分野別の正答率をバッジ（80%以上は緑、50%未満はオレンジなど）で視覚的に表示するようにしました。
- 間違えた問題（弱点）が蓄積されている場合のみ、通常の「学習スタート」ボタンとは別に「弱点克服 (N問)」という専用のアクションボタンが出現するようにしました。

## 確認方法
1. `npm run dev` でローカルサーバーを起動します。
2. コースを選択して通常通りクイズを解きます。わざと間違えるなどして結果画面まで進めてください。
3. トップ画面に戻ると、分野別正答率のバッジと「弱点克服」ボタンが表示されていることを確認できます。
4. 「弱点克服」ボタンを押すと、先ほど間違えた問題だけが再出題されます。

## 次のステップ
これにより、個人学習のPDCA（解く→弱点を知る→復習する）を回す基盤が完成しました。
今後は「忘却曲線（Spaced Repetition）の導入」や、「問題数のさらなる追加（スクリプトでの大量生成）」などを進めることで、学習効率をさらに高めることができます。
